# Crater Kings

Turn-based artillery game in one HTML file. Play it at https://shinigami1235-creator.github.io/Crater-Kings/ and install it from the browser menu to get it on your phone's home screen.

Online play uses PeerJS, so both players need the internet for that mode. Everything else works offline once the app is installed.

To update, replace `index.html` and bump `CACHE_VERSION` in `service-worker.js`.
